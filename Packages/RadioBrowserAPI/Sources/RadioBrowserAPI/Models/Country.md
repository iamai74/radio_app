# Country Model

This model represents a country from the Radio-Browser API, matching the specification provided in the API documentation.

## Fields

| Field | Type | Description |
|-------|------|-**------|
| name | String | Name of the country |
| stationCount | Int | Number of stations in this country |

## Notes

This model implements the `Country` protocol which defines the required properties that all country objects must have. The implementation follows the Radio-Browser API specification for consistent data handling across the application.

The fields have been updated to match the API specification, ensuring proper data mapping and handling.
