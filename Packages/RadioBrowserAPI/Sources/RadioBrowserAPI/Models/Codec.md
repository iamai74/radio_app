# Codec Model

This model represents a codec from the Radio-Browser API, matching the specification provided in the API documentation.

## Fields

| Field | Type | Description |
|-------|------|-**------|
| name | String | Name of the codec |
| stationCount | Int | Number of stations using this codec |

## Notes

This model implements the `Codec` protocol which defines the required properties that all codec objects must have. The implementation follows the Radio-Browser API specification for consistent data handling across the application.

The fields have been updated to match the API specification, ensuring proper data mapping and handling.
