# Language Model

This model represents a language from the Radio-Browser API, matching the specification provided in the API documentation.

## Fields

| Field | Type | Description |
|-------|------|-**------|
| name | String | Name of the language |
| stationCount | Int | Number of stations broadcasting in this language |

## Notes

This model implements the `Language` protocol which defines the required properties that all language objects must have. The implementation follows the Radio-Browser API specification for consistent data handling across the application.

The fields have been updated to match the API specification, ensuring proper data mapping and handling.
