# Tag Model

This model represents a tag from the Radio-Browser API, matching the specification provided in the API documentation.

## Fields

| Field | Type | Description |
|-------|------|-**------|
| name | String | Name of the tag |
| stationCount | Int | Number of stations with this tag |

## Notes

This model implements the `Tag` protocol which defines the required properties that all tag objects must have. The implementation follows the Radio-Browser API specification for consistent data handling across the application.

The fields have been updated to match the API specification, ensuring proper data mapping and handling.
